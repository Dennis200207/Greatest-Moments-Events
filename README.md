## Integration

This is the website component source, not a complete standalone application scaffold. To run it, add it to a React project configured with Tailwind CSS and install the dependencies required by the surrounding host project. The component itself uses React hooks and Tailwind utility classes.

## Notes

- The current gallery uses illustrative Unsplash photographs; replace them with approved company photographs before launch.
- The photo editor stores preview images in the current browser's local storage. It does not update a central media library or the live site for other visitors.
- The event enquiry action opens WhatsApp with the selected event details prefilled.
